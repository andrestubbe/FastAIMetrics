# Building FastAIMetrics from Source

## Prerequisites

- JDK 17+
- Maven 3.9+

## Build

```bash
mvn clean package
```

## Run Tests

```bash
mvn test
```

## Installation via JitPack

```xml
<dependencies>
    <dependency>
        <groupId>com.github.andrestubbe</groupId>
        <artifactId>FastAIMetrics</artifactId>
        <version>0.1.0</version>
    </dependency>
</dependencies>
```
